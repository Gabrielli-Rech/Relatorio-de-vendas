## 📊 Relatório de Vendas

Este projeto em Python gera relatórios de vendas a partir de dados fornecidos em formato JSON. Ideal para análise de desempenho de vendas, identificação de tendências e tomada de decisões estratégicas.

## 🚀 Funcionalidades

Leitura de Dados: Carrega dados de vendas a partir de arquivos JSON.

Análise de Vendas: Calcula totais de vendas, médias e outras métricas relevantes.

Geração de Relatórios: Cria relatórios formatados com as informações analisadas.

Exportação: Possibilidade de exportar os relatórios para formatos como CSV ou PDF.

## 🧰 Tecnologias Utilizadas

Linguagem: Python

Bibliotecas:

json: Para leitura e escrita de arquivos JSON.

pandas: Para manipulação e análise de dados.

matplotlib: Para geração de gráficos.

Formato de Dados: JSON
